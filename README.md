# LMS Web — MudBlazor Design Preview

Admin dashboard UI for the Laboratory Management System. This is a design-only starter and uses sample data.

## Requirements
- .NET 8 SDK

## Run
```bash
dotnet restore
dotnet run
```

Included screens: Dashboard, Students, Rooms & PCs, Vouchers, Lab Sessions, Reports, Audit Logs, Notifications, and Settings.

No database or LMS API connection is configured yet.
